

# Arkanoid Game

This is a game of Arkanoid developed in browser JavaScript with HTML5 Canvas 2D (no libraries, no build step). The objective of the game is to break all blocks using the ball that bounces off a paddle.

## Run

Serve the folder with a static server and open the page (opening `index.html` via `file://` can block audio and image loading):

```
python -m http.server
```

Then open http://localhost:8000.

## Controls

- Move the paddle: Left/Right arrows, A/D, or the mouse.
- Launch the ball and restart after game over: Space or click.
